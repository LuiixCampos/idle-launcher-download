# Idle Launcher — download

Todas as suas contas de jogos idle de navegador num app só.

**[Baixar o instalador para Windows](https://github.com/LuiixCampos/idle-launcher-download/raw/main/IdleLauncherSetup.exe)**

1. Baixe e abra o `IdleLauncherSetup.exe`.
2. Se o Windows mostrar o aviso do SmartScreen, clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Crie sua conta e comece o teste grátis de 7 dias.

Planos e dúvidas: https://idle-launcher.pages.dev
